# Methmetica v1.0.0 🧪

**Methmetica** 是一款基於節點（Node-based）的模組化數學運算工具。希望能夠做到像維基百科一樣，讓大家可以自由地編輯與分享自己的節點與工作流。

## 高度維基化
除了textnode與codenode，每一個節點都是由使用者們所一起構建出來的。
**你也可以出一分力**。

1.自訂義
**每一個節點_（除了textnode與codenode）_都是一個工作流**。當你遇到不懂的節點時，你可以點擊節點右鍵，選擇「查看工作流」，可以快速理解該工作流的行為。節點是由一層層的其他節點堆出來的，就像俄羅斯娃娃一樣，你可以一層層地往裡面挖，直到最底層的code node。
遇到不懂的觀念，查看網友們所留下的一個個說明，讓你恍然大悟。

此外，你可以將某個節點插入另一個節點，稱為plugin。plugin機制能夠讓你修改某一節點運作的行為（就算不是你的）。當你製作完一個節點，都可以到你想要被插入的節點的工作流去撰寫plugin，或是在製作節點的過程參考他人提交的被動plugin庫（這些會被推薦每個節點添加）來為自己的節點。
甚至你也可以自定義一個資料型別！

2.社群共創
每一個工作流分為私人、公開、和核心。
核心工作流專門保護那些重要的節點（如計算、定理等），**具有唯一性**。每個人都可以維護，然而提交核心工作流的修改都需要經過專家和貢獻者的審核。
公開工作流為一般用戶所建立，同一主題可能有多個工作流。你可以fork、like、comment他人的工作流。
理論上你也可以像canva那樣多人同時協作，如果我們有做出來的話。

3.版本控制
每一個版本都會被存到資料庫，你可以隨時回溯到過去的某一個版本。節點會根據該工作流是否有重大變更來決定是否自動更新。
推交更新時可以選擇為重大變革、錯誤修復、小修改、還是修編，決定是否要推送自動更新。

## 活躍社群
1.貢獻
你可以根據你的喜好，選擇主頁要推送「需完善」或「推薦」的工作流/節點，你可以找到需審核、需優化、需擴充、需修復等標籤的工作流/節點，並進行貢獻。

2.職階與等級
用戶分為匿名、一般用戶、貢獻者、初等專家、專家、管理員。
匿名為未登入用戶，一般用戶為註冊並驗證信箱的用戶，可以like comment fork 和上傳工作流。
貢獻者為信任的用戶，專家為具有某一方面專長的貢獻者，可以審核核心工作流。（初等專家沒有最終審核權，但可以審核並累積經驗，審核次數達標後可升為專家）
管理員為最高職權。

要他人使用自己的公開節點需要一個貢獻者審核，要創造新核心工作流也是。
發布或更新核心工作後需要一個專家和兩個貢獻者審核。

等級則是根據和社群的互動、貢獻度、登入天數、參加活動的獎勵等來決定，沒有實際意義，純粹好玩。

3.活動
定期舉辦各式活動（如核心擴張總招、工作流大賽、大工作流），讓大家可以交流與學習。
核心擴張總招：根據目前欠缺某一領域的核心節點，畫出一棵進度樹，讓大家可以依序貢獻，此時允許多人合作，所有參與貢獻和審核都會獲得獎勵。
工作流大賽：類似 Hackathon，給予一個題目，請大家發揮，並tag，不會選出實際的贏家，你可以以此增加自己的名聲。
大工作流：類似工作流大賽，每個人會在一個工作流中被分配到一個區塊的空間，可以根據題目發揮。這類型的題目通常比較簡單，或是偏向Blog、理論、教學。
