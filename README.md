# Methmetica v0.1.0 🧪

**Methmetica** 是一款基於節點（Node-based）的模組化數學運算工具。透過視覺化的連線，使用者可以自由串接數據與運算邏輯，並實現動態、可手動觸發的數學模型。

##高度維基化
除了textnode與codenode，每一個節點都是由使用者所一起構建出來的。
你也可以出一分力。

1.自訂義節點
**每一個節點都是一個工作流**。當你遇到不懂的節點時，你可以點擊節點右鍵，選擇「查看工作流」，可以快速理解該工作流的行為。
遇到不懂的觀念，查看網友們所留下的一個個說明，讓你恍然大悟！

此外，你可以將某個節點插入另一個節點，稱為plugin。plugin機制能夠讓你修改某一節點運作的行為。當你製作完一個節點，都可以到你想要被插入的節點的工作流去撰寫plugin，或是在製作節點的過程參考被動plugin庫來自己添加。

2.社群共創
每一個工作流分為私人、公開、和核心。
核心工作流專門保護那些重要的節點（如計算、定理等），**具有唯一性**。每個人都可以維護，然而提交核心工作流的修改都需要經過專家的審核。
公開工作流為為一般用戶所建立，同一主題可能有多個工作流。你可以fork、like、comment他人的工作流

3.版本控制
每一個版本都會被存到
